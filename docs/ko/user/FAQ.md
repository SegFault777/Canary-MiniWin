# 자주 묻는 질문

**실제 PC에서 돌아가나요?**
지금까지는 QEMU에서만 시험했습니다. 코드는 실제 하드웨어를 염두에 두고 짰지만(레거시 BIOS 부팅, IDE/AHCI/NVMe/SCSI/플로피 드라이버, ACPI 전원 끄기),
PC에는 레거시 BIOS나 UEFI의 "CSM" 모드가 필요하고 아직 실제 기기에서는 확인하지 못했습니다. 먼저 가상 머신에서 해 보세요.

**VMware / VirtualBox에서 돌아가나요?**
그것을 목표로 준비하고 있습니다. [VIRTUAL-MACHINES.md](../../en/user/VIRTUAL-MACHINES.md)(영어)를 보세요. 개발자는 둘 다 아직 돌려 보지 못했으니
오류 이름과 숫자를 적어 알려 주시면 큰 도움이 됩니다.

**USB(키보드, 마우스, 드라이브)를 지원하나요?**
키보드, 마우스, 태블릿은 됩니다(PS/2도 됩니다). xHCI, EHCI, OHCI 컨트롤러를 구동하며 키보드, 휠 마우스, "USB 태블릿"을 지원하고, `lsusb`가 찾은 장치를 보여 줍니다.
USB 허브, USB 메모리·드라이브, 인텔 UHCI 컨트롤러는 아직 지원하지 않습니다.

**64비트인가요?**
아니요, 32비트(i386) 시스템입니다. 64비트 버전은 나중 계획이고 아직 64비트 커널은 없습니다.

**윈도우나 리눅스 프로그램을 돌릴 수 있나요?**
아니요. 작은 API에 맞춰 C로 짠 자체 `.MWP` 프로그램만 돌립니다([MWP-PROGRAMS.md](../../en/dev/MWP-PROGRAMS.md), 영어; SDK는 [sdk/README.md](../../../sdk/README.md)).

**문서와 프로그램을 몇 개까지 둘 수 있나요?**
디스크에 자리가 있는 만큼입니다. MiniWin에는 진짜 파일 시스템(디렉터리, 커지는 파일, `/mnt`에 붙는 다른 디스크)이 있습니다.
[FILES-AND-DISKS.md](../../en/user/FILES-AND-DISKS.md)(영어)를 보세요. 문서는 메모장이 담을 수 있는 4 KB까지, 프로그램은 60 KB까지입니다.
바탕화면에는 처음 문서 64개와 프로그램 32개가 보입니다.

**저장하다가 전원이 나가도 데이터는 안전한가요?**
저장은 이름을 바꾸기 전에 새 버전을 완전히 쓰므로, 전원이 나가면 옛 문서 전체나 새 문서 전체 중 하나만 남고 뒤섞이지 않습니다. 기껏해야 닿을 수 없는
찌꺼기가 남는데 `part check <id> fix`가 되돌려 줍니다. (모든 동작의 모든 섹터에서 전원 차단을 흉내 내 시험했습니다.)

**디스크에 설치할 수 있나요?**
`os-inst`가 MiniWin이 볼 수 있는 다른 디스크나 파티션(IDE, SATA, SCSI, NVMe)에 MiniWin을 써 넣습니다. 조심스럽게 동작합니다 — 실행 중인 디스크는
덮어쓰기를 거부하고 `YES`를 직접 입력하게 합니다 — 하지만 대상은 **덮어씁니다**. [INSTALLING.md](../../en/user/INSTALLING.md)(영어)를 보세요.
